    DENTK dentk-gauss

    dentk-gauss is a command-line tool designed to apply Gaussian blur in three dimensions to large 3D image stacks stored in the DEN format. The tool leverages CUDA for accelerated processing and performs the Gaussian blur operation in the Fourier space for efficiency. By utilizing the separability property of the Gaussian filter, dentk-gauss applies the blur in two stages: a 2D Gaussian blur followed by a 1D Gaussian blur along the z dimension. This approach enhances data locality and speeds up processing for large datasets.

    Gaussian Filter Separability

    The Gaussian filter is separable, meaning a multi-dimensional Gaussian function can be decomposed into the product of one-dimensional Gaussian functions. This property allows the application of a 3D Gaussian blur to be split into three consecutive 1D Gaussian blurs along each dimension. Mathematically, a 3D Gaussian filter ( G(x, y, z) ) can be expressed as:

    [ G(x, y, z) = G(x) \cdot G(y) \cdot G(z) ]

    For more details on the Gaussian filter and its properties, you can refer to the Wikipedia page on Gaussian blur.

    Convolution Theorem

    The Convolution Theorem states that the Fourier transform of a convolution of two functions is the pointwise product of their Fourier transforms. This property allows us to apply Gaussian blur by:

    1. Taking the Fourier transform of the image.
    2. Taking the Fourier transform of the Gaussian kernel.
    3. Multiplying these two Fourier transforms together.
    4. Taking the inverse Fourier transform of the result to get the blurred image.

    Applying Gaussian Blur in 2D with Different (\sigma_x) and (\sigma_y)

    To apply a Gaussian blur in 2D with different standard deviations ((\sigma_x) and (\sigma_y)) for the x and y dimensions, follow these steps:

    1. Generate the 2D Gaussian Kernel: Create a Gaussian kernel in the spatial domain with the desired (\sigma_x) and (\sigma_y).
    2. Transform the Kernel: Compute the Fourier transform of this Gaussian kernel.
    3. Transform the Image: Compute the Fourier transform of the image.
    4. Multiply in the Frequency Domain: Multiply the Fourier transform of the image by the Fourier transform of the Gaussian kernel.
    5. Inverse Transform: Compute the inverse Fourier transform of the product to get the blurred image.

    Example Code in Python

    Start of the problem

    import numpy as np
from scipy.fft import fft2, ifft2, fftshift
from scipy.ndimage import gaussian_filter

def gaussian_kernel(shape, sigma_x, sigma_y):
    """Create a 2D Gaussian kernel."""
    m, n = [(ss - 1.) / 2. for ss in shape]
    y, x = np.ogrid[-m:m+1,-n:n+1]
    h = np.exp(-(x*x / (2*sigma_x*sigma_x) + y*y / (2*sigma_y*sigma_y)))
    h[h < np.finfo(h.dtype).eps * h.max()] = 0
    return h

def apply_gaussian_blur(image, sigma_x, sigma_y):
    """Apply Gaussian blur to an image using the Convolution Theorem."""
    # Create Gaussian kernel
    kernel = gaussian_kernel(image.shape, sigma_x, sigma_y)
    kernel /= np.sum(kernel)

    # Fourier transform of the image and the kernel
    image_ft = fft2(image)
    kernel_ft = fft2(kernel, s=image.shape)

    # Multiply in the frequency domain
    blurred_ft = image_ft * kernel_ft

    # Inverse Fourier transform to get the blurred image
    blurred_image = np.real(ifft2(blurred_ft))

    return blurred_image

    Example usage

    image = np.random.rand(512, 512)  # Replace with actual image
sigma_x, sigma_y = 2.0, 3.0
blurred_image = apply_gaussian_blur(image, sigma_x, sigma_y)

    Sigma in Pixels and Running Average

    The parameter (\sigma) in the Gaussian blur represents the standard deviation of the Gaussian function and is expressed in pixels. It defines the extent of the blur; a larger (\sigma) results in a blurrier image.

    To compare Gaussian blur with a running average (box blur) over a window (e.g., $10 \times 10$ pixels), you can relate the window size to (\sigma). A running average over a ( k \times k )window has an effect similar to a Gaussian blur with (\sigma = \frac{k} / 2.57 ). For example a $ 10 \times 10$ running average window corresponds to (\sigma = \frac{k} / 10/2.57 \approx 3.89 ). Visually, both methods will smooth the image, but the Gaussian blur provides a more natural, smooth transition compared to the abrupt edges of a running average.

    The factor 2.57 is derived empirically from comparing the effective width of a Gaussian function and a box filter. It is used to approximate the standard deviation (\sigma) of a Gaussian filter that has a similar smoothing effect to a box filter (running average) of size k. This factor remains constant for 1D and 2D and does not scale with the square.

    Implementation details

    Aforementioned separability is crucial for handling large datasets efficiently. By first applying a 2D Gaussian blur in the xy-plane and then a 1D Gaussian blur along the z-axis, the tool maximizes data locality and leverages the computational advantages of CUDA.

    CUDA and Data Locality

    To handle large datasets efficiently, dentk-gauss leverages CUDA for parallel processing. CUDA allows the tool to perform the Gaussian blur operation in the Fourier space, which significantly reduces the computational complexity.

    Data Locality Optimization

    Before applying the Gaussian blur in the third dimension, the tool transforms the data so that the z dimension is the fastest changing. This transformation ensures that the data is contiguous in memory, which enhances data locality and speeds up the operation. By performing the 2D Gaussian blur in the xy-plane first and then applying the 1D Gaussian blur along the z-axis, the tool minimizes cache misses and maximizes the efficiency of memory access.

    Command Line Interface

    The command line interface for dentk-gauss follows a similar structure to the existing tool dentk-framecalc1.

Positionals:
  input_den TEXT:FILE REQUIRED
                              Input file to add Gaussian blur.

    Conclusion

    dentk-gauss is a powerful tool for applying Gaussian blur to large 3D image stacks. By utilizing the separability property of the Gaussian function and leveraging CUDA for accelerated processing, it offers an efficient solution for handling large datasets. The command line interface provides flexible options for specifying the frames to process and the parameters of the Gaussian blur.
